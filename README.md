# 实验3：UML建模

## 实验目的
掌握面向对象设计，学会使用UML建模。

## 核心任务
1. 下载常用的UML建模软件，学会使用该软件
2. 基于实验2的需求分析，学会使用用例图描述需求
3. 基于课程设计选定系统的核心模块，给出一些用例描述
4. 绘制2个用例图（包含参与者、用例、关系）

## 实验内容

### 1. 用例描述
详细描述了图书管理系统的核心用例，包括：
- 用户登录
- 图书查询
- 图书借阅
- 图书归还
- 图书续借
- 图书录入
- 用户管理

每个用例包含：
- 用例名称
- 参与者
- 用例ID
- 优先级
- 前置条件
- 后置条件
- 基本流程
- 扩展流程

详细用例描述见`用例描述.md`文件。

### 2. UML用例图
使用PlantUML绘制了2个核心模块的用例图：

#### 2.1 用户管理用例图
包含参与者：学生、教师、管理员
包含用例：
- 用户注册
- 用户登录
- 用户信息查询
- 用户信息修改
- 用户角色管理
- 用户权限分配

用例图文件：`用户管理用例图.puml`

#### 2.2 借阅管理用例图
包含参与者：学生、教师、管理员
包含用例：
- 图书查询
- 图书借阅
- 图书归还
- 图书续借
- 图书预约
- 借阅记录查询
- 逾期提醒

用例图文件：`借阅管理用例图.puml`

## 实验成果
1. **用例描述文档**：详细描述了系统的核心用例，为系统设计提供了依据
2. **UML用例图**：绘制了2个核心模块的用例图，清晰展示了参与者与用例之间的关系
3. **UML建模技能**：掌握了使用PlantUML进行UML建模的方法

## 工具使用
- UML建模工具：PlantUML
- 语法格式：PlantUML语法
- 绘制内容：用例图
